# PackTrack IL v2.0 — אפליקציית ניהול משלוחים לאנדרואיד

## מה חדש בגרסה v2.0.0?
1. **כפתור "✓ קיבלתי" על כל כרטיס חבילה**: לחיצה אחת מסירה את החבילה מהתצוגה הפעילה (עם אפשרות ביטול `Undo` או מחיקה לצמיתות).
2. **בדיקה אוטומטית דרך הקישור והמייל אם המוצר נלקח (`LinkStatusVerifier.ts`)**: בודק את קישורי האיסוף/המעקב (כגון קישור התור של KSP, YDM, געש ודואר ישראל) ומזהה הזמנות שכבר נאספו (כולל שתי הזמנות KSP `954945978` ו-`954945953` שנאספו ב-12/10/2026) כדי להסיר אותן אוטומטית מהמערכת.
3. **סנכרון אוטומטי פעם ביום + סנכרון בכניסה + כפתור "סנכרן עכשיו" (`AutoSyncScheduler.ts`)**: מריץ סריקת רקע יומית קבועה (WorkManager / BackgroundFetch) ובדיקה מיידית בכל כניסה לאפליקציה או בלחיצה על כפתור הסנכרון.
4. **מערכת עדכון גרסה מובנית (`VersionUpdater.ts`)**: מאפשרת לבדוק ולהתקין עדכוני גרסה (OTA או הורדת APK מעודכן עם הרשאת `REQUEST_INSTALL_PACKAGES`) ולהחיל שינויים עתידיים מתוך האפליקציה בלי לאבד נתונים.
